# Security and reliability review

Threat model: unauthenticated internet clients, ordinary agents, administrators, cross-user/campaign object access, forged/replayed/late provider callbacks, malicious payload volume, untrusted media/storage responses, dependency compromise, queue/database/provider interruption. Audit used synthetic isolated systems only; production observation was read-only metadata/health.

## Confirmed boundaries and execution evidence

- Individual sessions/csrf/reset/invitation tokens are stored as hashes; Argon2 passwords; encrypted MFA; administrator MFA/replay/recovery; exact origin + header/cookie/stored CSRF comparison; secure cookie rotation, idle/absolute expiry, revocation and last-admin serialization. Actual fresh-database identity gate: `evidence/clean-identity.*`. The first contaminated-lab last-admin assertion is retained as a fixture-precondition failure, not hidden.
- Agent/admin and object-level permissions: real identity, campaign, calendar, callback, voice, inbound, reporting and incoming integration gates. Security is not inferred from hidden buttons. See each final gate in regression-results.md; unauthorized/stale/nonmember paths are explicit assertions.
- Reservation budgets now authenticate before shared charging, use actor UUID across sessions, stop on first denied counter, and reauthenticate before mutation. Independent limiter transactions never retain another pooled connection. Seven real HTTP/PG regressions cover anonymous depletion, personal/global denial, session rotation, bounded storage and concurrent legitimate calls.
- Signed callback HMAC uses configured canonical URLs, account and parent/child/intent bindings, bounded forms, duplicate fields/headers and durable replay checks. There is no provider timestamp freshness guarantee; replay protection relies on identity/state/idempotency, not signatures alone. Existing admitted callbacks drain while new admission is closed.
- Private archive/download/range paths validate fixed provider hosts, media format/hash/metadata, ownership, bounded playback and partial responses. Real local HTTP/object-store tests exercise failure/retry/auth; live Twilio/Spaces behavior remains external acceptance.
- Actual Nginx tests cover all14 canonical callback paths×4methods, oversized/idle bodies, auth prefix, representative120-callback burst and abusive rate enforcement. Default512KiB request budget preserves10MiB CSV PUT; separated exact-budget stress proves gateway/app survive64 over-budget and64 in-budget malformed requests. Five-second body timeout is idle-only, not an absolute slow-trickle deadline.
- Inspected queries parameterize user values. React text rendering escapes inspected labels/notes; validation errors omit submitted values; request logging omits raw bodies/tokens/exception messages. These code-review observations are not blanket dynamic injection/XSS coverage.
- Runtime/migration roles, no runtime DDL/environment-metadata writes, private DB network, disabled external communications, non-root/read-only containers, bounded pools/resources: actual foundation gate. Managed TLS verify-full/CA and fail-closed egress are reviewed/config-tested; current DigitalOcean trusted-source policy/IAM and host patch state were not independently revalidated.

## Dependencies and secrets

JavaScript advisory scan and locked Python OSV scan are recorded with UTC/commands under `evidence/npm-advisories.*` and `python-advisories.*`; zero advisory matches in those executed scans does not cover native image libraries. APK origin/version comparison used Alpine's official current [security database](https://secdb.alpinelinux.org/), captured snapshots and APK's own comparator. It found unpatched version ranges in API/gateway/broker and the local QA database image. See [primary advisory triage](evidence/backend/os-advisory-review.md): vendor severity, affected code paths, distribution conflicts and deployment scope are explicit. Installed package presence is not proof of remotely reachable exploitation. **Release dependency gate remains BLOCKED** until patch/rescan or justified per-issue VEX.

Repository secret scanning runs offline with verification disabled; raw scanner output contains hashes, not credentials (`evidence/repository-secret-scan.*`). Candidate triage and reachable-history marker scan are recorded separately. This is detection coverage, not proof that every credential is absent. Past conversation contained secret material; current external credential rotation/revocation is **NOT TESTED** and must be independently reviewed. No live secret values are copied into these reports; disposable credentials may appear in synthetic browser traces. No live provider credential-verification request was issued by a secret scanner.

Build/deploy source review: pinned actions/images, main-head/successful-CI/image revision/provenance checks, digest deployment, constrained forced-command SSH, separate migration credentials, active-call drain and rollback compatibility. No GitHub publish/deploy or external review approval was executed here. Incremental QA images reuse the cached matching pinned dependency environment; a clean production Docker build and its published attestation are separate gates. The attempted clean build failed with exit1 because the local audit disk filled, so clean-image verification remains BLOCKED. Only its own failed temporary container was removed.

## Explicit exclusions

BLOCKED: live carrier audio/SDK permissions on real devices; public provider routing/retries; real20-agent latency/audio/recording quality; destructive managed failover/host restore; production activation and credential rotation review.

NOT TESTED: exhaustive XSS/injection payload corpus, every135 endpoint permutation, continuous distributed slowloris, internet-scale abuse, all browser/OS combinations, formal cryptographic review, all historical high-entropy secrets, managed-provider internal package patch status. No penetration of external/unauthorized infrastructure was performed.

Offline detection executed:53 current candidates in19 files, all triaged as non-live fixture/public artifacts;99 reachable commits and983 text blobs scanned for targeted markers, zero matches. Full results and coverage limits: [secret triage](evidence/security/secret-triage.md), [history markers](evidence/security/secret-history-markers.json). No online credential verification occurred.
